# Connect to AIKOS

Configure your API endpoint and authentication to get started.

1. Open **Settings** → search for `aikos`
2. Set your **API URL** (e.g., `http://localhost:3000/api/v1`)
3. Run command **AIKOS: Set API Key** to securely store your key
4. The status bar will show **AIKOS: Connected** when ready

> Your API key is stored securely using VS Code's SecretStorage.
