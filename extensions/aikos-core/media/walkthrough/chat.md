# Ask Your First Question

Use the chat panel to ask questions about your codebase or knowledge collections.

1. Press `Ctrl+Shift+A` or click the **AIKOS AI** icon in the Activity Bar
2. Type your question in the chat input
3. Press **Enter** to submit
4. View the answer with source citations in the chat panel

## From the Editor
- Select code → right-click → **AIKOS: Explain Selection**
- Use `Ctrl+Shift+E` to explain the current selection

## Quick Commands
- `Ctrl+Shift+A` — Open chat and ask a question
- `Ctrl+Shift+E` — Explain selected code
- `Ctrl+Shift+R` — Review selected code
