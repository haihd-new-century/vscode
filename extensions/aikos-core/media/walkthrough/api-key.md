# Set Your API Key

An API key is required to connect the extension to the AIKOS AI backend.

1. Open the Command Palette (`Ctrl+Shift+P`)
2. Run **AIKOS: Open Settings**
3. Enter your API key in the **API Key** field
4. Click **Save**

## Where to find your API key
- Log in to your AIKOS dashboard
- Go to **Settings → API Keys**
- Copy the key and paste it here

## Tips
- Your API key is stored securely in VS Code's secret storage
- You can rotate or revoke keys from the dashboard at any time
