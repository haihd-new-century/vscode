# Select a Collection

Collections organize your documents and knowledge for RAG queries.

1. Open the **Collections** view in the AIKOS sidebar
2. Click a collection to select it as the active context
3. The selected collection appears in the status bar

## Adding Files
- Right-click any file in the Explorer → **AIKOS: Add File to Collection**
- Drag and drop files into the Collections view

## Tips
- Use project-specific collections for targeted answers
- Switch collections based on the domain you're working in
