# Submit Your First Agent Task

Let AIKOS agents handle complex multi-step tasks autonomously.

1. Press `Ctrl+Shift+T` or run **AIKOS: Submit Task** from the Command Palette
2. Describe the task in natural language
3. Monitor progress in the **Tasks** view in the sidebar
4. Approve or reject actions when prompted

## Task Examples
- "Refactor the auth module to use JWT tokens"
- "Write unit tests for the payment service"
- "Find and fix all SQL injection vulnerabilities"

## Approvals
High-risk actions require your approval before execution. You'll see a notification with **Approve** / **Reject** buttons in the Approvals panel.
