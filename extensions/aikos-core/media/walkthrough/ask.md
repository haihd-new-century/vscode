# Ask AIKOS

Use the chat panel or inline commands to ask questions about your codebase.

## From the Chat Panel
Click the AIKOS icon in the Activity Bar to open the chat panel, then type your question.

## From the Editor
1. Select code in the editor
2. Right-click → **AIKOS: Explain Selection** (or use `Ctrl+Shift+E`)
3. The answer appears in the chat panel with source citations

## Quick Commands
- `Ctrl+Shift+A` — Ask a question
- `Ctrl+Shift+E` — Explain selected code
- `Ctrl+Shift+R` — Review selected code
